# Theming and customization

Every color, font, size, radius and shadow comes from a CSS variable named `--erp-*`. Override them in your own stylesheet; the library never needs to be rebuilt.

```css
/* app.css */
:root {
  --erp-color-primary: #7a1fa2;
  --erp-color-primary-hover: #63168a;
  --erp-color-primary-subtle: #f3e5f8;
  --erp-color-focus: #7a1fa2;
  --erp-radius: 0;
}
```

**Your values always win.** The defaults are declared with `:where(:root)`, which has zero specificity, so a plain `:root` rule in your CSS overrides them no matter which stylesheet loads first.

## Scoped themes and density

- Set tokens on any element to theme only that part of the page: dark mode (`[data-theme='dark'] { … }`), a brand per tenant, a highlighted panel.
- Set `data-density="compact"` on any ancestor for the small control size (or use the **Density** toolbar above).

## Restyling one component

Every component accepts `className` and renders stable `erp-*` classes and `data-*` state attributes (listed in each component's **Styling** table in `docs/components`). Prefix your rules with an app-level class so they win:

```css
.my-app .erp-button[data-variant='primary'] {
  border-radius: var(--erp-radius-pill);
}
```

## Main tokens

- **Typography**: `--erp-font-family`, `--erp-font-size-xs` … `--erp-font-size-2xl`, `--erp-font-weight-medium`, `--erp-font-weight-bold`
- **Surfaces and text**: `--erp-color-bg`, `--erp-color-bg-subtle`, `--erp-color-bg-muted`, `--erp-color-bg-hover`, `--erp-color-text`, `--erp-color-text-muted`
- **Brand and focus**: `--erp-color-primary`, `--erp-color-primary-hover`, `--erp-color-primary-subtle`, `--erp-color-on-primary`, `--erp-color-focus`
- **Status**: `--erp-color-danger`, `--erp-color-warning`, `--erp-color-success`, `--erp-color-info` (each with `-subtle`)
- **Shape and space**: `--erp-radius-sm`, `--erp-radius`, `--erp-radius-lg`, `--erp-space-1` … `--erp-space-6`
- **Controls**: `--erp-control-height`, `--erp-control-padding-x` (and `-sm` variants)
- **Grids**: `--erp-color-selected`, `--erp-color-changed`, `--erp-color-added`
- **Charts**: `--erp-chart-1` … `--erp-chart-8`

The full list with defaults is in `docs/THEMING.md` and `src/styles/tokens.css`.
